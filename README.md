# BMW Global Sales Dashboard (2010–2024)

## 📊 Project Overview

This project was developed as part of the Data Analyst Internship - Task 4.

The objective was to design an interactive Power BI dashboard that helps business stakeholders analyze BMW sales performance using historical sales data from 2010 to 2024.

The dashboard provides key performance indicators, sales trends, regional analysis, vehicle model performance, fuel type distribution, transmission analysis, and sales category insights.

---

## 🎯 Objectives

- Build an interactive Power BI dashboard
- Visualize business KPIs
- Analyze sales trends over time
- Compare regional sales performance
- Identify top-selling BMW models
- Explore fuel type and transmission distribution
- Enable dynamic filtering using slicers

---

## 📁 Dataset

**Dataset:** BMW Sales Data (2010–2024)

The dataset contains approximately 50,000 records with information including:

- Model
- Year
- Region
- Fuel Type
- Transmission
- Price (USD)
- Sales Volume
- Mileage
- Engine Size
- Sales Classification

---

- Sales Category Distribution

### Interactive Filters

- Year
- Region
- Model
- Fuel Type
- Transmission

## 📌 Business Insights

The dashboard enables users to:

- Monitor sales performance over time
- Compare regional sales
- Identify high-performing BMW models
- Analyze customer preferences by fuel type
- Compare automatic and manual transmission sales
- Filter data dynamically for better decision-making
